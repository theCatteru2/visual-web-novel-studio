# 📖 Guía de Uso del Editor

* **Línea Temporal (Timeline):**
  * **+ 💬 Diálogo:** Inserta una nueva viñeta en la escena activa.
  * **+ 🔀 Decisión:** Agrega elecciones interactivas y bifurcaciones.
  * **◀ / ▶:** Reordena la posición de las viñetas en la secuencia.
  * **📋 Duplicar:** Copia la viñeta actual manteniendo personajes y posiciones.

* **Gestión de Personajes en Escenario:**
  * **Añadir / Quitar:** Pulsa sobre los personajes en la barra superior para colocarlos o retirarlos del lienzo.
  * **Arrastrar y Posicionar:** Mueve el sprite directamente en pantalla; el editor lo ajusta magnéticamente a las ranuras y a la línea de suelo.
  * **Ajustes:** Toca al personaje en el lienzo para cambiar su expresión facial, brillo (0-100%), tamaño y animación de entrada.

* **Bifurcaciones y Decisiones:**
  * Escribe la pregunta del dilema y define cada una de las opciones.
  * Configura el destino de cada botón: continuar recto, saltar a una vía/rama específica o modificar variables de la partida.

* **Memoria y Variables:**
  * Crea interruptores (Sí/No) o contadores numéricos para medir afinidad o registrar eventos de la historia.
  * Modifica variables al tomar decisiones para desbloquear rutas condicionales.

* **Fondos y Escenarios:**
  * Pulsa **🖼️ Fondo** para alternar entre los escenarios disponibles en la galería o importar imágenes locales.

* **Guardar y Compartir:**
  * **💾 Exportar / 📂 Importar:** Descarga tu historia como archivo `.json` a tu dispositivo o carga proyectos guardados previamente.
  * **🌐 Publicar en la Comunidad:** Sube tu novela a la galería pública para que otros usuarios puedan jugarla en línea o descargarla si habilitas el permiso.
